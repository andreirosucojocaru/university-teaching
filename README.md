# University Teaching

Lab materials and source code from my time teaching hands-on labs at the **Faculty of Automatic Control and Computers, Politehnica University of Bucharest** (2010–2017), and from the **D'Android 2015** programming course organized by [ROSEdu](http://www.rosedu.org).

Each folder was originally a separate repository. They were merged here with their full commit history, so nothing was lost.

## Contents

| Folder | Course | Academic year | What's inside |
| --- | --- | --- | --- |
| [`integrated-enterprise-applications/2014-2015`](integrated-enterprise-applications/2014-2015) | Integrated Enterprise Applications (*Aplicații Integrate pentru Întreprinderi*), 4th year, 1st semester | 2014/2015 | Java EE labs 00–10 |
| [`mobile-programming/2014-2015`](mobile-programming/2014-2015) | Android programming labs, 4th year, 2nd semester | 2014/2015 | Labs 01–10, including a client/server lab |
| [`mobile-programming/2013-2014`](mobile-programming/2013-2014) | Android programming labs, 4th year, 2nd semester | 2013/2014 | Labs 05, 07, 08, 09 |
| [`mobile-programming/dandroid-2015/lab05`](mobile-programming/dandroid-2015/lab05) | D'Android 2015 (ROSEdu) | 2015 | Lab tasks and solutions |
| [`mobile-programming/dandroid-2015/lab06`](mobile-programming/dandroid-2015/lab06) | D'Android 2015 (ROSEdu) | 2015 | Lab tasks and solutions |
| [`mobile-programming/dandroid-2015/lab07`](mobile-programming/dandroid-2015/lab07) | D'Android 2015 (ROSEdu) | 2015 | Lab tasks and solutions |

The lab texts inside each folder are in Romanian, as they were written for Romanian students.
